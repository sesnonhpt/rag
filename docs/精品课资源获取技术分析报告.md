### 阶段2: 页面文字提取 ❌

**目标**: 从课程页面提取文字内容

**尝试方案**:

#### 方案A: urllib/requests直接访问
```python
response = requests.get(course_url)
```

**结果**: ❌ **失败 - HTTP 403 Forbidden**

**原因**: 
- 网站有反爬虫保护
- 检测User-Agent和请求头
- 需要有效的Cookie/Session

#### 方案B: 添加完整的浏览器headers
```python
headers = {
    'User-Agent': 'Mozilla/5.0...',
    'Referer': 'https://basic.smartedu.cn/',
    'Accept': 'text/html...',
    # ... 10+ headers
}
```

**结果**: ❌ **仍然403**

**原因**: 
- 服务器端有更复杂的验证机制
- 可能检查TLS指纹、请求顺序等

#### 方案C: Playwright浏览器自动化
```python
browser = await playwright.chromium.launch()
page = await browser.new_page()
await page.goto(url)
content = await page.content()
```

**结果**: ⚠️ **部分成功**
- 能访问页面 (HTTP 200)
- 但页面内容是JavaScript动态加载的
- 提取到的文字很少 (只有295字的导航信息)

### 阶段4: 文件下载 ❌

**目标**: 下载PDF教案和视频

#### 尝试1: 直接下载PDF
```bash
curl "https://r1-ndr-private.ykt.cbern.com.cn/.../pdf.pdf"
```

**结果**: ❌ **HTTP 403 Forbidden**

**原因**: URL中包含 `-private`，需要认证

#### 尝试2: 使用Playwright带Cookie下载
```python
# 先访问课程页面获取Cookie
await page.goto(course_url)
# 再下载PDF
response = await page.goto(pdf_url)
```

**结果**: ❌ **HTTP 401 Unauthorized**

**原因**: 
- PDF URL需要特殊的访问令牌
- Cookie不足以授权
- 可能需要动态生成的临时token

#### 尝试3: 视频下载
```
视频URL格式: .m3u8 (HLS流媒体)
加密方式: DRM (Digital Rights Management)
```

**结果**: ❌ **完全无法下载**

**原因**:
- 视频使用DRM加密
- 需要专用的解密密钥
- 密钥由服务器动态生成，绑定用户会话
- 即使下载了加密的视频片段，也无法播放

## 🚫 技术障碍总结

### 1. 反爬虫保护 (高)
- ✅ 可以绕过 (使用Playwright)
- ⚠️ 但页面内容动态加载，提取困难

### 2. 内容认证机制 (极高)
- ❌ 无法绕过
- PDF/文档需要特殊令牌
- 令牌生成机制未知

### 3. DRM视频加密 (极高)
- ❌ 完全无法绕过
- 需要破解DRM (违法)
- 技术上极其困难

### 4. 法律风险 (极高)
- 页面明确标注: "未经允许不得转载或引用"
- 批量下载可能违反服务条款
- DRM破解属于违法行为

## 🎯 最终建议

### 放弃精品课内容获取，原因：

1. **技术障碍**: DRM加密、认证机制无法突破
2. **法律风险**: 可能违反平台服务条款
3. **投入产出比低**: 花费大量时间，成功率极低
4. **有更好的替代方案**: 专注导学案分析

### 转向导学案深度分析，优势：

1. ✅ **文件可控**: 用户上传，无技术障碍
2. ✅ **无法律风险**: 用户自己的文件
3. ✅ **价值更高**: 直接帮助老师改进导学案
4. ✅ **技术成熟**: 已有完整的解析和分析能力

class SmartEduDirectSearch:
    SEARCH_API_URL = "https://x-search.ykt.eduyun.cn/v1/resources/combine/search"
    
    def search(self, keyword: str, max_results: int = 12):
        request_body = {
            "keyword": keyword,
            "tab_codes": ["qualityCourse", "prepareLesson", ...],
            "limit": max_results
