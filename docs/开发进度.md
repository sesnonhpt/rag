## 技术架构

### 前端
- React + TypeScript
- Quill 富文本编辑器
- Tailwind CSS

### 后端
- FastAPI
- LLM API (OpenAI/Azure)
- 文件解析服务
- 备课思路提取服务 (`TeachingThoughtExtractor`)
- 音频转写服务（Whisper API）

### 核心组件
```
TemplateEditorPage
├── 左侧：Quill 编辑器
└── 右侧：辅助面板
    ├── TeachingThoughtsTimeline（备课思路）
    ├── ContentEnhancer（内容加强）
    └── 导出按钮
```

### API 接口
- `GET /api/templates/{filename}/content` - 获取文件内容
- `POST /api/templates/extract-teaching-thoughts` - 提取备课思路
- `POST /api/templates/ai-modify` - AI 修改文本
- `POST /api/templates/{filename}/export` - 导出文档
- `POST /api/templates/course-to-draft/stream` - 流式生成教学设计
