# Quick Start - Tool-Using Writer Agent

## 5 分钟快速开始

### 1. 安装依赖

```bash
# 已包含在现有依赖中，无需额外安装
pip install httpx  # 用于 Web Search API 调用
```

### 2. 配置环境变量

```bash
# .env
TOOL_USING_ENABLED=true

# 可选：配置 Web Search API
WEB_SEARCH_API_KEY=your_tavily_api_key_here
WEB_SEARCH_PROVIDER=tavily

# 可选：配置 LaTeX 渲染
LATEX_RENDERER_ENABLED=true
```

### 3. 运行演示

```bash
# 运行工具演示
.venv/bin/python scripts/demo_tool_using.py

# 运行单元测试
.venv/bin/python -m pytest tests/unit/test_tools.py -v
```

### 4. 集成到现有系统

#### 方式 1：在 API 层集成

```python
# app/services/lesson_service.py

from src.agents.tools import WebSearchTool, ImageRetrievalTool, LaTeXRendererTool
from src.agents.tools.base import ToolExecutor

def create_orchestrator(...):
    # 初始化工具
    tools = [
        WebSearchTool(),
        ImageRetrievalTool(image_resources=image_db),
        LaTeXRendererTool(),
    ]
    tool_executor = ToolExecutor(tools)
    
    # 创建 orchestrator
    return LessonOrchestrator(
        planner_agent=planner,
        query_agent=query_agent,
        retriever_agent=retriever,
        writer_reviewer_agent=writer,
        conversation_agent=conversation,
        trace=trace,
        tool_executor=tool_executor,  # 添加这一行
    )
```

#### 方式 2：在 Orchestrator 初始化时集成

```python
# 在创建 orchestrator 的地方
from src.agents.tools import WebSearchTool, ImageRetrievalTool, LaTeXRendererTool
from src.agents.tools.base import ToolExecutor

# 初始化工具
tools = [
    WebSearchTool(),
    ImageRetrievalTool(),
    LaTeXRendererTool(),
]
tool_executor = ToolExecutor(tools)

# 传入 orchestrator
orchestrator = LessonOrchestrator(
    ...,
    tool_executor=tool_executor,
)
```

### 5. 验证工具是否工作

```python
# 生成教案
result = orchestrator.run(
    topic="量子计算最新进展",
    template_category="comprehensive",
    conversation_state=state,
)

# 检查工具结果
print(f"Tool results: {len(result['tool_results'])}")
for tool_result in result['tool_results']:
    print(f"  - {tool_result['tool_name']}: {tool_result['success']}")
```

## 常见问题

### Q1: 工具不执行怎么办？

**A**: 检查以下几点：
1. `TOOL_USING_ENABLED=true` 是否设置
2. `tool_executor` 是否传入 orchestrator
3. 查看日志确认工具是否被规划

### Q2: Web Search 总是失败？

**A**: 这是正常的降级行为：
- 如果没有配置 `WEB_SEARCH_API_KEY`，工具会优雅失败
- 系统会继续使用 RAG 结果生成教案
- 不影响主流程

### Q3: 如何禁用工具系统？

**A**: 设置环境变量：
```bash
TOOL_USING_ENABLED=false
```

### Q4: 如何添加自定义工具？

**A**: 参考 `docs/TOOL_USING_AGENT.md` 的"扩展性"章节
