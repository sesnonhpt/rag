## 技术亮点

### 1. 并行执行
```python
# 工具并行执行，提高性能
results = await executor.execute_parallel([
    {"tool_name": "web_search", "params": {...}},
    {"tool_name": "image_retrieval", "params": {...}},
])
```

### 2. 优雅降级
```python
# 工具失败不影响主流程
if not self.api_key:
    return ToolResult(
        success=False,
        error="API key not configured",
        metadata={"degraded": True},  # 标记为降级
    )
```

### 3. 超时保护
```python
# 自动超时处理
result = await asyncio.wait_for(
    tool.execute(**params),
    timeout=tool.timeout,  # 默认 10 秒
)
```

### 4. 完整的可观测性
```python
# 所有工具调用都有日志
logger.info(
    "tool_executor.execute_success tool=%s elapsed_ms=%.1f",
    tool_name,
    elapsed_ms,
)
```

## 架构改进

### 之前的架构
```
PlannerAgent → QueryAgent → RetrieverAgent → WriterReviewerAgent
                                                    ↓
                                            只能使用 RAG 结果
```

### 现在的架构
```
PlannerAgent → ToolPlanner → ToolExecutor → WriterReviewerAgent
       ↓            ↓              ↓                ↓
   决定主题    决定工具      并行执行        整合所有信息
                                                    ↓
                                    RAG 结果 + 工具结果 + 最新信息
```

## 使用示例

### 1. 基础使用
```python
from src.agents.tools import WebSearchTool, ImageRetrievalTool, LaTeXRendererTool
from src.agents.tools.base import ToolExecutor

# 初始化工具
tools = [
    WebSearchTool(api_key="your_key"),
    ImageRetrievalTool(image_resources=images),
    LaTeXRendererTool(),
]

# 创建执行器
executor = ToolExecutor(tools)

# 执行工具
results = await executor.execute_parallel([
    {"tool_name": "web_search", "params": {"query": "量子计算"}},
])
```

### 2. 集成到 Orchestrator
```python
orchestrator = LessonOrchestrator(
    planner_agent=planner,
    query_agent=query_agent,
    retriever_agent=retriever,
    writer_reviewer_agent=writer,
    conversation_agent=conversation,
    trace=trace,
    tool_executor=executor,  # 传入工具执行器
)
```
