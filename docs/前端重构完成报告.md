## 核心功能

### 1. 教案生成 (LessonPage)

**功能**:
- 表单输入（主题、备注、模板类型、模型选择）
- SSE 流式生成，实时显示进度
- Markdown 渲染预览
- 参考文档展示
- 导出 DOCX

**技术实现**:
- 使用 `useLesson` Hook 管理状态
- EventSource API 实现 SSE 流式请求
- marked 库渲染 Markdown
- Blob API 实现文件下载

### 2. Chat 对话 (ChatPage)

**功能**:
- 实时对话界面
- 消息历史记录
- Markdown 渲染
- 自动滚动到最新消息

**技术实现**:
- 使用 `useChat` Hook 管理对话状态
- useRef + useEffect 实现自动滚动
- 区分用户和助手消息样式

### 3. PPT 编辑器 (PPTEditorPage)

**状态**: 占位页面，待后续开发

- 幻灯片列表管理

- 导出 PPTX

## API 集成

### 开发环境代理

Vite 配置了代理，将 `/api` 请求转发到后端:

```typescript
server: {
  port: 8080,
  proxy: {
    '/api': {
      target: 'http://localhost:8000',
      changeOrigin: true,
      rewrite: (path) => path.replace(/^\/api/, '')
    }
  }
}
```

### 生产环境

生产环境通过 Nginx 反向代理:

```nginx
location /api {
  proxy_pass http://backend:8000;
  proxy_set_header Host $host;
  proxy_set_header X-Real-IP $remote_addr;
}
```

## 性能优化

1. **代码分割**: React Router 自动按路由分割代码
2. **懒加载**: 可以使用 `React.lazy()` 懒加载组件
3. **缓存**: Nginx 配置静态资源缓存
4. **Gzip**: Nginx 启用 Gzip 压缩
5. **Tree Shaking**: Vite 自动移除未使用的代码
